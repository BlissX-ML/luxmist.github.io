# Solunote - 我的个人项目及技术实践

> 这是一个基于 React + Vite 构建的个人技术项目，
> 主要用于实践前端工程化、内容渲染系统、数据可视化与交互设计相关能力，
> 并作为长期维护的技术实验与作品展示平台。
> 同时已完成域名购入、域名解析、ICP备案与公安备案等完整上线部署流程，具备真实生产环境运行条件。

## **项目亮点**：

1. **D3.js 地图的深度定制与交互**
    - 基于 D3.js 从底层实现地图渲染逻辑，手动构建中国地图与省级地图的可视化展示。
    - 支持双向钻取交互：双击进入省级视图，点击空白区域返回全国视图，并同步更新视图状态。

2. **前端工程化：自动化处理资源**
    - OSS 图片转码：后端统一生成图片地址，非 WebP 图片通过 OSS 图片处理在取图时转换，无需手动执行转换脚本。
        - [图片后端转发原理与代码说明](server/_data/oss-image-proxy.md)。
        - 前端本地静态图片仍由 Vite 构建插件自动压缩。
    - 文件预扫描： 由于是静态网站，通过 `npm run convert:scanPublic` 命令可以自动扫描 public 目录下的 Markdown 文件并生成所需的数组结构。
        - 将部分运行时处理前移至构建阶段，从而减少页面加载时的运行时开销。

3. **状态管理与代码组织**
    - 解耦状态： 使用 `useContext` 处理全局基础配置，用 `Redux` 接管核心组件的状态，避免出现 Props Drilling 的问题。
    - 样式模块化： 为每个 `.jsx` 组件配置独立的 `.scss` 文件，这样在修改样式时非常直观，也避免了 CSS 样式污染。

4. **Markdown 渲染与代码高亮**
    - 构建了基于 Markdown + Front Matter 的轻量内容系统，实现内容与渲染逻辑解耦，并支持自动索引与结构化内容加载。
    - 基于 react-markdown 库实现 markdown 文件的渲染与显示。
    - 自定义 markdown 文件中，各个元素的显示样式，并引入 prism-themes 库对多行代码块进行了视觉优化。

## **技术栈清单**：

1. 核心： React 19, Vite
2. 可视化： D3.js
3. 状态管理： Redux, Context API
4. 工具： Node.js（构建脚本）、Sharp（资源优化）、SCSS（样式模块化）
5. 部署： Vercel, 轻量级服务器, Github Pages
